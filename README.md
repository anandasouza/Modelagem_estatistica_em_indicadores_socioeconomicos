## Modelagem Estatística de Indicadores Socioeconômicos e Expectativa de Vida

Este projeto tem como objetivo analisar como diferentes fatores socioeconômicos e de saúde influenciam a expectativa de vida em diversos países.
A partir de um modelo estatístico, foi possível identificar os principais determinantes que afetam a longevidade e gerar insights relevantes para políticas públicas e estratégias de saúde.


O projeto foi desenvolvido em Python, utilizando as seguintes bibliotecas:

pandas / numpy → manipulação e limpeza de dados
seaborn / matplotlib → visualização estatística
statsmodels → construção e análise do modelo estatístico (OLS)
scikit-learn (StandardScaler) → padronização das variáveis
warnings → controle de mensagens de alerta durante a execução


### Metodologia

Coleta e preparação dos dados: tratamento de valores ausentes, normalização e padronização dos indicadores.

Análise exploratória (EDA): inspeção de correlações, distribuições e outliers.

Modelagem estatística: aplicação do modelo de regressão linear OLS (Ordinary Least Squares) para estimar a relação entre os indicadores e a expectativa de vida.

Interpretação dos resultados: análise dos coeficientes, significância estatística e poder explicativo do modelo.
